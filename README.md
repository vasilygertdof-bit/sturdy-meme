# Четыре слова
Простое мобильное веб-приложение для ребёнка, который пока не говорит.

Четыре большие кнопки: 👍 ДА, 👎 НЕТ, 🙋 ХОЧУ, 🆘 ПОМОГИ.

Нажатие произносит соответствующее слово с помощью встроенного синтеза речи браузера. Никакой сервер, регистрация, база данных или API не нужны.

## Запуск
Откройте `index.html` в браузере. На телефоне можно разместить все файлы в корне репозитория GitHub и опубликовать статический сайт на Vercel.

Для речи должен быть включен звук и доступен русскоязычный голос устройства. Качество произношения зависит от браузера и ОС.

## Файлы
- `index.html` — кнопки
- `style.css` — сетка 2 × 2 и оформление
- `script.js` — озвучивание
